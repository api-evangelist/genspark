# Genspark

> Genspark is an all-in-one AI workspace and autonomous "Super Agent" platform. It plans and executes multi-step tasks and bundles AI agent tools for research, slides, sheets, docs, chat, calling, and a built-in AI browser. Genspark exposes a hosted Model Context Protocol (MCP) server so external agents can discover and call its tools over HTTP under OAuth. Backed by Emergence Capital.

## Agent / MCP surface
- Hosted MCP server (HTTP): https://www.genspark.ai/api/mcp
- OAuth authorization-server metadata: https://www.genspark.ai/.well-known/openid-configuration
- MCP OAuth scopes: mcp:tools:read, mcp:tools:call, mcp:resources:read, mcp:prompts:read
